# Job Studio

Локальное веб-приложение для поиска вакансий, подготовки писем и заполнения анкет. Встроенный MCP-сервер позволяет управлять теми же вакансиями из Codex.

## Запуск на Windows

Нужны Python 3.11 и Chrome. В PowerShell из корня репозитория выполните

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start_job_studio.bat
```

Сервер открывает браузер на свободном порту на 127.0.0.1. Для запуска без открытия окна используйте `python -m job_studio.server --no-browser`.

## Настройка

В настройках заполните профиль, укажите путь к PDF-резюме, предпочтения и источники. Ключ Infercom можно сохранить через интерфейс. Gemini использует GEMINI_API, необязательная настройка модели — GEMINI_MODEL. Браузерный адаптер Upwork при входе читает UPWORK_EMAIL и UPWORK_PASSWORD. Для ключей и учётных данных поддерживаются переменные окружения и существующая системная связка ключей UpWorkAITool.

Состояние хранится в job_studio_data. Чтобы использовать прежнюю базу, профиль и анкеты, задайте JOB_STUDIO_DATA как абсолютный путь к имеющейся папке данных до запуска веб-сервера и MCP. Одной папкой данных одновременно управляет один веб-сервер.

## Работа

- Настройте источники и фильтры. Сбор сохраняет вакансии в SQLite, учитывает повторяющиеся объявления и сортирует результаты по дате публикации.
- Используйте Parse Plus для отдельной ссылки. Gemini и Infercom готовят письма по фактам из профиля.
- Откройте вакансию и нажмите «Откликнуться». Браузерный обработчик заполняет поддерживаемые анкеты, прикладывает CV и отслеживает результат. Ответы на дополнительные вопросы можно проверить в интерфейсе.
- Журнал показывает этапы работы. Если сайт потребует ручного действия, форму можно закончить самостоятельно. Отмечайте ручную отправку после подтверждения сайта.

## MCP для Codex

Запустите веб-сервер. В конфигурацию MCP клиента добавьте секцию с абсолютными путями к Python из виртуального окружения и к точке входа. Пример для Codex

```toml
[mcp_servers.job_studio]
command = 'C:\Projects\job-studio-web\.venv\Scripts\python.exe'
args = ['C:\Projects\job-studio-web\job_studio\mcp_entry.py']
```

MCP использует stdio и находит активный веб-сервер по локальному endpoint.json. Доступны сбор, список и разбор вакансий, редактирование писем, запуск отклика, ответы на вопросы и просмотр событий.

## Источники и обработка объявлений

Для Ashby и Workable приложение читает публичные ленты работодателей. Для сайтов с HTML-объявлениями оно извлекает ссылки и данные JobPosting, включая компанию, описание, город, даты публикации и закрытия, когда сайт их предоставляет. В начальной конфигурации есть Just Join IT, No Fluff Jobs и несколько карьерных страниц. Список URL, слова для включения и исключения и лимит сбора меняются в настройках. Полнота выдачи зависит от конкретной страницы источника.

Для Upwork предусмотрены отдельные адаптеры карточки и Best Matches. Чтобы добавить ленту, укажите в источниках https://www.upwork.com/nx/find-work/best-matches. Для единичной вакансии используйте Parse Plus. Существующая карточка открывается повторно по известному URL. В интерфейсе доступны отдельные действия для разбора ссылки и запуска отклика.

## Жизненный цикл отклика

1. Соберите объявления без генерации или сразу с черновиками. Список можно фильтровать по тексту и статусу. Сначала показываются известные свежие даты.
2. Откройте карточку, прочитайте исходное объявление и письмо. Черновик можно исправить, сохранить или скопировать. Источник фактов для генерации — заполненный профиль. При включённом резервном провайдере сервис пробует второго, если вызов первого завершился ошибкой.
3. По команде отклика открывается видимый браузер. Обработчик распознаёт поддерживаемую форму, включая встроенные окна, вносит известные данные, прикрепляет резюме и пытается отправить анкету. Если площадка меняет разметку или переводит на незнакомую форму, может потребоваться ручное заполнение.
4. Для неизвестного обязательного вопроса сервис может подготовить предложение по профилю и тексту PDF. Пользователь проверяет его в интерфейсе либо вводит свой ответ. Подтверждённые текстовые ответы можно сохранить для повторного использования.
5. После ручного действия можно продолжить автоматическое заполнение, остановить попытку или отметить самостоятельно завершённый отклик. В истории видны этапы, ошибки и результат. При неподтверждённой отправке сначала проверьте квитанцию сайта или почту.

## Что доступно агенту через MCP

| Инструмент | Когда вызывать |
|---|---|
| `studio_status` | Узнать состояние сбора, Parse Plus и текущего отклика, увидеть вопросы кандидату. |
| `collect_vacancies` | Запустить сбор. Передайте `generate_letters=false`, чтобы сначала выбрать объявления. |
| `stop_collection` | Остановить текущий сбор. |
| `list_vacancies` | Получить компактную страницу, отфильтрованную по тексту или статусу. Максимум 50 карточек за запрос. |
| `get_vacancy` | Загрузить описание, письмо и историю одной выбранной карточки. |
| `parse_vacancy` | Импортировать одну ссылку через Parse Plus. |
| `save_letter` | Сохранить проверенный текст письма. |
| `start_application` | Запустить заполнение и отправку для выбранного ID. Успех вызова означает старт процесса. |
| `answer_questions` | Передать ответы на открытые вопросы текущей формы. |
| `application_action` | Продолжить или отменить попытку, либо зафиксировать ручную отправку после подтверждения. |
| `recent_events` | Прочитать новые события после сохранённого курсора, до 50 за вызов. |

Для разбора подборки начните с краткого списка, запрашивайте подробности только у выбранных ID и передавайте возвращённый курсор следующему вызову журнала. Так второй агент сможет продолжить работу по ID вакансии и последнему событию.

## Локальные данные и внешние сервисы

SQLite содержит объявления, черновики и историю. Рядом хранятся настройки, профиль кандидата, служебный адрес сервера и подтверждения отправок. Браузерные профили создаются локально в каталоге данных. Резюме выбирается по пути на компьютере. Для общей разработки каждый участник использует собственные профиль, ключи и базу.

При генерации письма AI-провайдер получает профиль и описание вакансии. Для подсказки по анкете в запрос могут входить текст резюме и вопрос работодателя. При запуске отклика браузер передаёт выбранной площадке данные кандидата и приложенный файл.

## Организация кода

- job_studio/static — HTML, стили и JavaScript интерфейса.
- job_studio/browser — управление сессиями Chrome, профилями и адаптеры Upwork.
- job_studio/core.py — сбор, хранение вакансий и генерация писем.
- job_studio/applications.py, site_bots.py, questions.py — заполнение анкет, обработчики площадок и вопросы кандидату.
- job_studio/server.py и mcp_server.py — веб-API и MCP-инструменты.
- tests — проверки сбора, свежести, Parse Plus, заполнения анкет и MCP.

Для проверки из корня проекта запустите `python -m unittest discover -s tests`.

Порядок доработок, критерии приёмки и разделение задач между участниками описаны в [PLAN.md](PLAN.md).
